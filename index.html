🔐 Owner PIN
PIN protects sensitive buttons in this interface. It is not server-level security; use a secure backend for stronger protection.
⚠️ The default owner PIN is still 1234. Change it before using this system for real business records.

   
🖨️ Network print bridge
For direct text printing, run a trusted local Windows bridge that accepts POST requests and sends raw text to the Xprinter. Do not expose an unauthenticated print endpoint to the internet.
Printer TCP port: 9100
Keep the Xprinter XP-T80Q and Windows PC on the same local network. Browser/iPhone direct raw TCP printing is not supported; use the secured local bridge on your PC. If the hosted HTTPS page cannot reach an HTTP bridge, browser mixed-content security may block it; use a trusted HTTPS bridge or a secure local app rather than disabling browser security.

  

  
🧾 Receipt Designer
Customize plain-text thermal receipt content and line width. Preview text size affects only the on-screen sample; physical print size depends on the printer bridge and printer settings. These settings are saved on this browser and apply to new prints and reprints.

🗓️ Daily archive
Automatic archive time: 6:00 AM — Iraq time (Asia/Baghdad). The site checks when opened or active; it archives eligible completed sessions without deleting income, extra sales, bills, or previous archives. A static page cannot run a timer while completely closed, so any missed archive runs on next open.

  
⚠️ Full business-data reset
Permanently deletes local records on this device. Download a backup first. Use only if you really intend to reset the business.
