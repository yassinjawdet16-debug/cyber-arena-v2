⚙️ Settings

Changes are saved on this device's browser.

🔐 Owner PIN

PIN protects sensitive buttons in this interface. It is not server-level security; use a secure backend for stronger protection.

🧾 Receipt design — 80 mm thermal

Plain-text receipt, approximately 42 characters per line, for 80 mm paper. Settings apply to previews and new print jobs. The printer itself must be loaded with 80 mm rolls.

🖨️ Network print bridge

For direct text printing, run a trusted local Windows bridge that accepts POST requests and sends raw text to the Xprinter. Do not expose an unauthenticated print endpoint to the internet.

Printer's previously reported address was 192.168.1.41, port 9100. Verify current IP. Browser/iPhone direct raw TCP printing is not supported; the bridge must be installed and configured on your PC.

🗓️ Daily archive

Automatic archive time: 6:00 AM — Iraq time (Asia/Baghdad). The site checks when opened or active; it archives eligible completed sessions without deleting income, extra sales, bills, or previous archives. A static page cannot run a timer while completely closed, so any missed archive runs on next open.

🧹 Clear history (protected)

Archives completed sessions before clearing the current history. Financial records and bills are not deleted.
